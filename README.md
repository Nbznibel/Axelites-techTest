# Panier — Maison Lefort

Le module qui calcule le total d'un panier sur la boutique en ligne Maison Lefort (thés et accessoires). TypeScript, sans framework.

```bash
npm install
npm test
```

| Fichier | Rôle |
|---|---|
| `REGLES.md` | Les règles de calcul, telles que validées avec la boutique. **C'est la référence.** |
| `src/panier.ts` | Le code, en production depuis six mois. |
| `tests/panier.test.ts` | Les tests, ils passent. |
| `MESSAGE-CLIENT.md` | Un message reçu par le service client. |
| `REPONSES.md` | À remplir par vous. |
